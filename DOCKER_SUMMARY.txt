🚀 TWO WAYS TO RUN GYM SYSTEM:

═══════════════════════════════════════════════════════════════
OPTION 1: WITH DOCKER (Recommended)
═══════════════════════════════════════════════════════════════

1. Install Docker Desktop
   → Read: DOCKER_INSTALLATION_GUIDE.md
   → Download: https://www.docker.com/products/docker-desktop
   → Follow: Step 1-4 in guide

2. Start Docker services
   cd c:\GYM
   docker-compose up -d
   
3. Setup database
   .\setup-db.ps1
   
4. Start backend (new terminal)
   .\start-backend.ps1
   
5. Start frontend (another terminal)
   .\start-frontend.ps1

Result: PostgreSQL and Redis run in Docker containers!

═══════════════════════════════════════════════════════════════
OPTION 2: LOCAL POSTGRESQL (No Docker)
═══════════════════════════════════════════════════════════════

1. Install PostgreSQL locally
   → Download: https://www.postgresql.org/download/
   → Or use Windows Store
   
2. Setup database
   cd c:\GYM
   .\setup-db.ps1
   
3. Start backend (new terminal)
   .\start-backend.ps1
   
4. Start frontend (another terminal)
   .\start-frontend.ps1

Result: PostgreSQL runs natively on your machine!

═══════════════════════════════════════════════════════════════

✅ WITH DOCKER:
   ✓ No local PostgreSQL needed
   ✓ Services isolated in containers
   ✓ Easy cleanup (docker-compose down)
   ✓ Easy to manage multiple services
   ✓ Industry standard for development

✅ WITH LOCAL POSTGRESQL:
   ✓ Works if Docker unavailable
   ✓ Direct database control
   ✓ No Docker overhead
   ✓ Simpler if already using PostgreSQL locally
