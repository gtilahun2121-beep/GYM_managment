📖 QUICK START GUIDE
────────────────────────────────────────────────────────────────

1️⃣  OPEN POWERSHELL
    Press Win+X → Select "Windows PowerShell"

2️⃣  NAVIGATE TO PROJECT
    cd c:\GYM

3️⃣  SETUP DATABASE
    .\setup-db.ps1
    (Press Enter for default values)

4️⃣  START BACKEND (in new PowerShell)
    .\start-backend.ps1
    
    Wait for: "NestFactory bootstrapped successfully"

5️⃣  START FRONTEND (in another new PowerShell)
    .\start-frontend.ps1
    
    Wait for: "ready in ... ms"
